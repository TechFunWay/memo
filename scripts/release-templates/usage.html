📝 备忘录 使用说明

版本 {{VERSION}} — 单文件部署，开箱即用

🚀 快速启动

方式一：二进制直接运行

# Linux / macOS
tar -xzf techfunway-memo-{{VERSION}}-linux-amd64.tar.gz
cd techfunway-memo-{{VERSION}}-linux-amd64
./start.sh

启动后浏览器打开 http://localhost:8905，第一个注册的用户自动成为管理员。

方式二：Docker

docker run -d \
  --name memo \
  -p 8905:8905 \
  -v ./data:/app/data \
  techfunways/memo:latest

方式三：飞牛 NAS（fnOS）

  1. 下载对应架构的 .fpk 包
  2. 打开飞牛桌面 → 应用中心 → 手动安装
  3. 选择 .fpk 文件，按向导完成安装
  4. 访问 http://<你的NAS IP>:8905

🔧 启动参数说明

参数默认值说明
-port8905服务监听端口
-data-dir./data数据目录（数据库、上传文件、日志全部在此目录下）
-web-dir./static前端静态文件目录（通常无需修改）

使用示例

# 默认配置
./memo

# 指定端口和自定义数据目录
./memo -port 8080 -data-dir /mnt/disk1/memo-data

# 仅修改端口
./memo -port 9000

📁 数据目录结构

data/
├── db/
│   └── database.db      # SQLite 数据库（核心数据！）
├── upload/               # 上传的图片（按 YYYYMMDD 分类）
└── logs/                 # 运行日志
⚠️ 重要：database.db 包含所有备忘录和用户数据，请定期备份。升级时只需替换二进制文件，数据库会自动迁移。

🐳 Docker 部署详解

端口映射

# 将宿主机 8080 端口映射到容器内的 8905 端口
-p 8080:8905

数据持久化

容器内数据存储于 /app/data，必须挂载到宿主机目录以避免数据丢失：

-v /宿主机路径/data:/app/data

完整运行命令

docker run -d \
  --name memo \
  -p 8905:8905 \
  -v /etc/memo/data:/app/data \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  techfunways/memo:latest

Docker Compose

# docker-compose.yaml
version: '3.8'
services:
  memo:
    image: techfunways/memo:latest
    container_name: memo
    ports:
      - "8905:8905"
    volumes:
      - ./data:/app/data
    environment:
      - TZ=Asia/Shanghai
    restart: unless-stopped
# 启动
docker compose up -d

# 查看日志
docker compose logs -f

# 停止
docker compose down

Docker 升级

docker pull techfunways/memo:latest
docker stop memo && docker rm memo
# 用相同的数据卷参数重新启动
docker run -d --name memo -p 8905:8905 -v ./data:/app/data techfunways/memo:latest
💡 提示：升级时保留数据卷不变，数据不会丢失。数据库会自动迁移到新版本。

🏠 飞牛 NAS 部署

安装

  1. 下载对应架构的 .fpk 包
  2. 打开飞牛桌面 → 应用中心 → 手动安装
  3. 选择下载的 .fpk 文件
  4. 在配置向导中设置应用端口（默认 8905）
  5. 点击完成，等待安装完成

升级

在应用中心点击 手动安装，选择新的 .fpk 文件，系统自动识别为升级，保留原有数据。

数据位置

飞牛 NAS 的数据存储于应用数据目录（通常位于 /vol1/@appdata/techfunway-memo/）。

🖥️ 开机自启（Linux systemd）

创建 /etc/systemd/system/memo.service：

[Unit]
Description=Memo Service
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/opt/memo
ExecStart=/opt/memo/memo -port 8905 -data-dir /opt/memo/data
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable memo
sudo systemctl start memo

🔄 升级方法

二进制方式

  1. 下载新版本压缩包
  2. 停止当前运行的 memo 进程
  3. （可选）备份数据目录
  4. 替换 memo 二进制文件
  5. 重新启动 memo

Docker 方式

docker pull techfunways/memo:latest
docker stop memo && docker rm memo
docker run -d --name memo -p 8905:8905 -v ./data:/app/data techfunways/memo:latest

飞牛 NAS 方式

应用中心 → 手动安装 → 选择新 .fpk 文件即可升级。

✅ 所有方式升级时数据库自动迁移，无需手动操作。建议升级前备份数据目录。

🔐 管理员密码重置

# 使用命令行重置（需要服务器本地操作）
./memo -reset-admin -admin-pass 新密码

也可以通过环境变量传递密码：

ADMIN_PASS=新密码 ./memo -reset-admin

如果忘记了密码且无法命令行操作，可以通过数据库直接重置：

# 使用 sqlite3 工具操作数据库
sqlite3 data/db/database.db "UPDATE users SET password='新密码的MD5' WHERE is_admin=1"

密码加密方式：MD5(MD5(明文密码) + "memo")。
